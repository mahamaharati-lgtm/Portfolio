01 — Selected work

Featured project

One substantial project, built end to end and documented in depth.

React · TypeScript · XYFlow

Workflow Studio

An enterprise approval workflow builder for designing, validating, publishing and simulating approval processes.

Problem

Approval processes such as purchases, leave and expenses follow rules, like “finance must approve anything over ₹50,000”. When those rules live in email threads, requests stall and nobody can see why a request went where it did.

My role

Sole designer and frontend engineer: product scope, interaction design, component architecture, the validation and simulation engine, accessibility, automated tests and documentation.

Stack

  • React 19
  • TypeScript
  • Vite
  • Tailwind CSS
  • React Router
  • XYFlow
  • Zustand
  • React Hook Form
  • Zod
  • Radix UI
  • Vitest
  • Playwright
  • axe-core
Read the case study Live demo Source code

Key interactions

  • Drag steps onto a canvas and connect named outputs: Approved, Rejected, Returned, Yes and No
  • Live validation against business rules, with “Show step” to jump to each problem
  • Publishing is blocked until the workflow is valid, and versions are tracked
  • Step-by-step simulation of an ₹85,000 purchase request with a full request history
  • Undo/redo, JSON import/export and save/restore in the browser

UX decisions

  • A structured List view replaces the canvas on phones instead of shrinking it
  • One draft is shared by the canvas, list and property panel, so every path follows the same rules
  • Errors are phrased as fixes (“Choose an approver role for …”) and shown on the step itself

Accessibility

  • Keyboard alternatives for dragging: arrow keys move steps, and connection selects replace edge dragging
  • Status, severity and branch meaning use text and icons, never colour alone
  • axe-core in Playwright: 0 WCAG 2.1 A/AA violations across key screens in light and dark

02 — About

Frontend engineering with a UI/UX focus

I’m a frontend software engineer based in Bengaluru. I started as a Frontend Developer Intern at Neviton in July 2025, became an Associate Software Engineer there in January 2026, and joined Pivot Path as an Associate Software Engineer (Frontend) in July 2026.

Most of my work is in React and TypeScript, styled with Material UI or Tailwind CSS and connected to REST APIs. I like breaking a design into small, predictable components, keeping state where it belongs, and checking layouts on real screen sizes rather than only on a wide monitor.

I care about interfaces that work for everyone. That means semantic HTML first, visible focus, keyboard paths for every pointer interaction, and errors that tell people what to do next. My Workflow Studio case study shows how I applied this to a complex, canvas-based editor.
